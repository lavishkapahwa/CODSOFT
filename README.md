# CodSoft Internship Projects

This repository contains three Python data analytics projects completed as part of my CodSoft internship.

## Task 1: Student Performance Data Cleaning and Preprocessing
- Cleaned and prepared student performance data.
- Checked missing values and duplicate records.
- Saved the cleaned dataset for further analysis.

## Task 2: HR Employee Attrition Analysis
- Explored employee attrition data using Pandas.
- Analyzed attrition across departments and job satisfaction levels.
- Created visualizations using Matplotlib and Seaborn.

## Task 3: Air Quality Analysis and Visualization
- Inspected and cleaned air quality data.
- Generated summary statistics.
- Created pollutant trend charts and a correlation heatmap.

## Tools and Technologies
